# Haushalts-Tool

Web-App zur Haushaltsplanung für mehrere Personen: gemeinsamer Kalender (Dienstpläne +Termine), Essenswunschliste, Rezeptbuch und Einkaufszettel.

## Status
🚧 In aktiver Entwicklung - noch keine lauffähige Version.

## Geplante Features
- Dienstplan / Schichtplanung (individuell pro Person, mit wiederverwendbaren Vorlagen)
- Gemeinsamer Kalender für Termine
- Essenwunschliste
- Rezeptbuch mit Zutaten-Import in den Einkaufszettel
- Einkaufszettel (mehrere Listen parallel)
- Dashboard mit Tages-/Wochenübersicht
- Flexible Anzahl an Profilen, responsive für Handy/Tablet/Desktop

## Tech-Stack
- Backend: Python
- Frontend: Angular, HTML/CSS
